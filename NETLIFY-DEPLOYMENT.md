# Netlify deployment

1. Extract the ZIP and upload the folder containing `index.html` to Netlify Drop, or connect the GitHub repository.
2. Publish directory: `.`. Build command: leave empty.
3. In Netlify dashboard, enable Forms detection and redeploy.
4. Confirm the `contact` form appears under Forms.
5. Configure email notifications and send a real test enquiry before launch.

The portfolio is static HTML/CSS/JavaScript. The design-reference screenshots are NOT bundled or used as site backgrounds; the layouts, gradients, borders, waves, network effects, icons and card structures are recreated with CSS/HTML/SVG. The genuine profile portrait, project artwork, fonts, favicon and resume are retained.

Private GitHub repositories (Smart Blood Bank, DonationDesk, RideRent) remain linked but public visitors cannot access them unless repository access is granted. Review secrets and demo credentials before changing repository visibility.
