# Hariharan P — Java Full Stack Developer Portfolio

A responsive, single-page portfolio built with static HTML, CSS and browser JavaScript. No framework, package manager or build step is required.

## Design implementation

The approved portfolio references have been recreated as code:
- Glassmorphism navigation with circular scroll-progress ring, active-section marker and subtle animated purple/blue wave glow.
- Dark navy hero with CSS grid/network atmosphere, real portrait, technology orbit labels and metric cards.
- About section with professional timeline and core-focus cards; no duplicate portrait.
- Eight skill-category cards and a CSS-built developer/code banner.
- Six project cards with supplied project artwork, compact layout, technology badges and genuine configured links only.
- Experience timeline, achievements dashboard, education timeline and certification cards.
- Two-column contact section with a CSS-built illustration, contact information, highlights and Netlify form.
- Footer with code-generated wave effects, navigation, social links, resume and back-to-top control.

Reference screenshots are used only as visual guidance. They are not embedded, displayed, or used as website background images. The page's real portrait, project artwork, fonts and resume remain as site assets.

## Files

- `index.html` — page content and browser interactions.
- `reference-design.css` — reference-based responsive visual system and CSS artwork.
- `site-config.js` — real project repository and available demo destinations.
- `assets/` — actual portrait and six project artwork files.
- `fonts/` — locally hosted Syne and DM Sans fonts.
- `Hariharan_P_Java_Full_Stack_Developer_Resume.pdf` — downloadable resume.
- `netlify.toml` and `_headers` — static Netlify settings and response headers.
- `NETLIFY-DEPLOYMENT.md` — deployment instructions.
- `PORTFOLIO-REFERENCE-QA.md` — QA results and remaining deployment checks.

## Preview locally

From this folder run:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to Netlify

Publish the repository root. Build command is empty; publish directory is `.`. Enable Netlify Forms in the dashboard and redeploy. Submit a real test enquiry and verify the submission and email notification before launch.

## Project links and access

All six project cards have their genuine GitHub destinations configured. Smart Blood Bank, DonationDesk and RideRent are private repositories in the project notes; public visitors cannot view them unless access is granted or visibility is changed. Review secrets, personal data and demo credentials before making any repository public.

Only the WarrantyWise demo is linked because it is the documented live destination. No fake demo URLs are used for projects without a verified public demo.
