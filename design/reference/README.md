# Portfolio design references

This folder contains the approved visual-reference bundle for the portfolio sections. The original section files are packaged in **[portfolio-section-reference-images.zip](./portfolio-section-reference-images.zip)**.

The archive contains:

- 00 — Full portfolio overview
- 01 — Navbar
- 02 — Home / Hero
- 03 — About
- 04 — Skills
- 05 — Projects
- 06 — Experience
- 07 — Achievements
- 08 — Education
- 09 — Certifications
- 10 — Contact
- 11 — Footer

These files are design documentation only. They are not referenced by the website's HTML, CSS or JavaScript and are not served as runtime page backgrounds. The live portfolio remains code-based.

The original section designs were retrieved from the account's ChatGPT image library. The Home / Hero reference is a crop from the full portfolio overview to isolate that section. Images are stored as optimized WebP previews within the ZIP to keep the repository lightweight.
