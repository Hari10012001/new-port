## Usage

These images are **design documentation only**. They are not loaded by the website's HTML, CSS or JavaScript, are not CSS backgrounds, and do not add any runtime network requests. The live portfolio remains implemented in HTML, CSS and JavaScript.

The original reference images were retrieved from the account's ChatGPT image library and converted to optimized WebP previews (maximum width 320 px) to keep the repository lightweight. The Home / Hero image is a crop from the full overview because that overview contains the dedicated hero composition.

Use the visuals to compare layout, hierarchy, color, glow and spacing. Do not copy generated sample metrics, employment details, credentials, project claims or text without verifying them against the authoritative resume and source code.
